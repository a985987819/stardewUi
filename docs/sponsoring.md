## 怎么换成我自己的二维码

> 这一节面向**接手维护这个仓库的人**。如果你只是来用库的，跳过即可。

### 1. 准备图片

用微信「赞赏」功能生成二维码，保存为 PNG。建议：

| 项 | 建议值 | 原因 |
| --- | --- | --- |
| 格式 | PNG | 微信扫码对 JPEG 有时识别不稳|
| 尺寸 | ≥ 400×400 | README 里按 220px 展示，太小的原图在高分屏会糊 |
| 留白 | 保留 | 部分扫码器对贴边二维码识别率下降 |
| 文件名 | `donate-qr.png` | 下方引用路径写死了这个名字 |
| 体积 | < 100KB | 会被README 和 npm 页面反复加载 |

### 2. 放到指定位置

```text
docs/assets/donate-qr.png
```

**注意目录是 `docs/assets/`**，不是 `public/`。原因：这个二维码只在文档里被引用，
不参与演示站构建，放进 `public/` 会被Vite 当静态资源拷进 `dist/`，白占产物体积。

先建目录：

```bash
mkdir -p docs/assets
```

### 3. 提交并推送

```bash
git add docs/assets/donate-qr.png
git commit -m "docs: 添加赞赏码"
git push
```

推送后 GitHub 会在几分钟内通过 `raw.githubusercontent.com` 提供图片，
README 里的图片引用随即生效。

### 4. 同步到其他位置

图片路径在下面这几处被引用，换图时确认都指向同一张：

- `README.md` → 「请我喝杯咖啡」章节
- `README_EN.md` → "Buy me a coffee" section
- 若你在演示站首页放了赞赏入口，同步更新对应文案

### 5.不想公开收款码？

把上面 `<img>` 整块删掉，只留文字说明即可。**不写金额、不放码、不解释**是完全没问题的选择，
提 Issue 问「二维码在哪」的人依然能得到回答。
